# 🐳 VPS Deployment: Rock-Paper-Scissors (Docker + Coolify)

## О проекте

Это одностраничная HTML-игра «Камень, Ножницы, Бумага», которая использовалась как **тестовый стенд** для отработки навыков контейнеризации и развертывания приложений. Сама игра намеренно проста — вся ценность проекта в инфраструктурной части: от написания `Dockerfile` до автоматического деплоя на удалённый VPS через платформу **Coolify**.

## Что демонстрирует проект (Ключевые навыки)

- **Написание `Dockerfile`** на базе легковесного образа `nginx:alpine` для раздачи статического HTML.
- **Сборка Docker-образа** и проверка работы контейнера локально.
- **Развертывание контейнера на удалённом VPS**: установка Docker, запуск и публикация приложения.
- **Настройка автоматического деплоя** через платформу [Coolify](https://coolify.io): push в репозиторий → пересборка образа → обновление контейнера без ручных действий на сервере.

## Инструкция по локальному запуску (через Docker)

1. Убедитесь, что Docker установлен и запущен.
2. Соберите образ:

   ```bash
   docker build -t rock-paper-scissors .
   ```

3. Запустите контейнер:

   ```bash
   docker run -p 8080:80 rock-paper-scissors
   ```

4. Откройте в браузере: [http://localhost:8080](http://localhost:8080)

## Инструкция по деплою на VPS (кратко)

1. **Установка Docker на сервер** (Ubuntu/Debian):

   ```bash
   curl -fsSL https://get.docker.com | sh
   ```

2. **Запуск контейнера с игрой** на сервере:

   ```bash
   docker run -d --name rps -p 80:80 rock-paper-scissors
   ```

3. **Автоматический деплой через Coolify**: подключите Git-репозиторий в Coolify, укажите путь к `Dockerfile` — платформа будет пересобирать и перезапускать контейнер при каждом push в ветку проекта.
