# Камень, Ножницы, Бумага

Одностраничная HTML-игра «Камень, Ножницы, Бумага» с минималистичным тёмным дизайном.

## Запуск

Приложение не требует установки зависимостей или сервера:

1. Откройте файл `index.html` в браузере (двойной клик по файлу).
2. Готово — игра запущена.

## Как играть

1. Нажмите одну из трёх кнопок: **Камень**, **Ножницы** или **Бумага**.
2. Компьютер случайно выбирает свой вариант.
3. Отображается результат раунда, очки обновляются автоматически.

### Правила

- **Камень** бьёт **ножницы**.
- **Ножницы** бьют **бумагу**.
- **Бумага** бьёт **камень**.
- Одинаковый выбор — ничья.
